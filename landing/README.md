# landing

Built with [Stack](https://github.com/NishantGits/stack).

## Develop

```bash
stk dev          # live reload at http://localhost:3000
stk build        # static HTML → dist/
stk themes       # list themes
```

## Pages

| File | URL |
|------|-----|
| `index.stk` | `/` |
| `about.stk` | `/about` |
| `docs.stk` | `/docs` |

Add a new `.stk` file to create a route.
